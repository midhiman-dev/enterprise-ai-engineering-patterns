# Evaluation Artifacts

This directory stores observational execution reports generated by the Corrective RAG golden-scenario evaluation harness (`scripts/evaluate_golden_scenarios.py`).

## File Format

Each live run generates a timestamped JSON file:
`crag-golden-evaluation-<YYYYMMDDTHHMMSSZ>.json`

## Schema Structure

```json
{
  "metadata": {
    "evaluation_type": "golden_scenario_live",
    "timestamp_utc": "2026-08-31T12:00:00Z",
    "model": "openai/gpt-oss-120b",
    "kb_snapshot": "Kubernetes website v1.31 (snapshot-initial-v1.31 / commit 20d164c)",
    "chroma_collection": "corrective-rag-kb",
    "retriever_top_k": 4,
    "generation_max_attempts": 2,
    "notice": "This is an observational live evaluation using nondeterministic external models/providers."
  },
  "scenario_results": [
    {
      "scenario_id": "Q1_LOCAL_KNOWN",
      "query": "Why does kubectl get pods show CrashLoopBackOff?",
      "started_at_utc": "...",
      "completed_at_utc": "...",
      "elapsed_ms": 1234.56,
      "model": "openai/gpt-oss-120b",
      "final_status": "ANSWERED",
      "final_answer": "...",
      "generation_attempts": 1,
      "observed_trace_steps": ["retrieve", "grade_documents", "generate", "hallucination_check"],
      "used_web_search": false,
      "rewritten_query": null,

      "final_sources": [...],

      "expected_behavior": "...",

    }
  ],

    "total_scenarios": 3,

```

Generated `.json` evaluation run files are excluded from git tracking by default via `.gitignore` to preserve clean repository history.
